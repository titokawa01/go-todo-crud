HTTPハンドラとは？

ブラウザがURLにアクセスすると、Goサーバーはそのリクエストを処理します。

この処理を行う関数を HTTPハンドラ と呼びます。

HandleFunc

Goでは URL と処理を http.HandleFunc で紐付けます。 


http.HandleFunc("/", handler)

このコードは次の意味になります。

  • URL「/」にアクセス
  • handler関数を実行

Handler関数

handler関数は HTTPリクエストを処理します。 


func handler(w http.ResponseWriter, r *http.Request) {

fmt.Fprintln(w, "Hello World")

}

このコードはブラウザに「Hello World」を表示します。

処理の流れ

Webアプリは以下の流れで動作します。 


Browser
 ↓
HTTP Request
 ↓
Go Server
 ↓
Handler
 ↓
Response
