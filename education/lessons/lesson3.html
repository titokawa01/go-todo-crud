HTMLテンプレートとは？

GoのWebアプリではHTMLテンプレートを使って画面を表示します。

テンプレートを使うことで、サーバーのデータをHTMLに埋め込むことができます。

テンプレートを読み込む

Goでは template.ParseFiles を使ってHTMLファイルを読み込みます。 


tmpl, err := template.ParseFiles("templates/index.html")

このコードは HTMLテンプレートを読み込む処理です。

テンプレートを実行する

読み込んだテンプレートは Execute で表示します。 


tmpl.Execute(w, data)

ここでHTMLがブラウザに送信されます。

処理の流れ


Browser
 ↓
HTTP Request
 ↓
Go Server
 ↓
DBからデータ取得
 ↓
HTMLテンプレートにデータを渡す
 ↓
Browserに表示

演習

main.go を開いて次のコードを探してください。 


tmpl.Execute(w, data)

このコードは何をしているでしょうか？

  • HTMLを読み込む
  • HTMLをブラウザに送る
  • DB接続を行う
