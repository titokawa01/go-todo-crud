.gitignoreとは？

.gitignore は「Gitに含めないファイル」を指定するファイルです。

誤って不要なファイルや機密情報をGitHubにアップしないために使います。

.gitignore を設定しないと事故につながります

よく除外するファイル


.env
node_modules/
.DS_Store
  • .env → パスワードなどの情報
  • node_modules → サイズが大きい
  • .DS_Store → Macの不要ファイル

.gitignoreの書き方

プロジェクトのルートに .gitignore を作成します。 


touch .gitignore

中身は次のように書きます。 


.env
node_modules/
.DS_Store

よくある事故

新人がよくやるミスです。

  • .env をGitHubにアップしてしまう
  • node_modules を丸ごとpushする
  • 不要ファイルが増えてリポジトリが重くなる
一度pushしたファイルは完全削除が難しいです

git status で確認する

pushする前に必ず確認します。 


git status

意図しないファイルが含まれていないか確認しましょう。
