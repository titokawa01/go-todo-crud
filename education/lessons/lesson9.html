Webアプリの全体の流れ

ここまでのレッスンをつなげると、Webアプリは次のように動きます。 


Browser
 ↓
HTTP Request
 ↓
Go Handler
 ↓
Database
 ↓
HTML Template
 ↓
Browserに表示

リクエストの流れ（コード）


http.HandleFunc("/", handler)

func handler(w http.ResponseWriter, r *http.Request) {

rows, _ := db.Query("SELECT id, content FROM tasks")

tmpl, _ := template.ParseFiles("templates/index.html")

この1つの関数の中で、すべての処理がつながっています。

それぞれの役割

  • Browser → ユーザーの操作
  • Handler → リクエスト処理
  • Database → データ保存
  • Template → 画面表示

重要なポイント

Webアプリは「流れ」で理解することが大切です

単体のコードではなく、処理のつながりを意識しましょう。
