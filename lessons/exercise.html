演習

ここでは、実際にタイピングして答える練習をします。 最初は短い答えから始めて、少しずつ長いコードに慣れていきましょう。

まずは入力してみて、正解と見比べながら覚えていくのがおすすめです。
用語集へ

初級1

まずは、ファイル名や基本的な下準備のコードから慣れていきましょう。

初級1
Goプログラムの中心となるファイル名を入力してください。
ヒント: この教材では、最初に作るファイルです。
初級1
フォームの値を Go で読めるようにする処理を入力してください。
正解例: r.ParseForm()
ヒント: FormValue の前に呼ぶことが多いです。

初級2

URLと処理のつながり、そしてリクエストの見方を確認します。

初級2
URL と handler を結びつけるコードを入力してください。
正解例: http.HandleFunc("/", handler)
ヒント: どのURLに、どの処理を呼ぶかを登録します。
初級2
リクエストの HTTP メソッドを確認するときに使う値を入力してください。
正解例: r.Method
ヒント: GET か POST かを見分けるときに使います。

中級

テンプレートや SQL の基本を、少し長めのコードで確認します。

中級
テンプレートにデータを渡して画面に反映する処理を書いてください。
正解例: tmpl.Execute(w, data)
ヒント: テンプレートを「動かす」処理です。
中級
ID を条件に tasks テーブルのデータを削除する SQL を入力してください。
正解例: DELETE FROM tasks WHERE id = ?
ヒント: WHERE で対象を絞ります。
