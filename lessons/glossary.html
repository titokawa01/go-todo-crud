Goの基本

Goの入り口

Go

Google が開発したプログラミング言語です。 この研修では、Webアプリを作るために使います。

例: Go でサーバーを立てて、ブラウザに画面を返します。
プロジェクト管理

module

Go のプロジェクトを管理する単位です。 go mod init で作ります。

例: go mod init example.com/go-todo-crud
実行開始点

main.go

Go プログラムの中心になるファイルです。 package main と func main() がよく出てきます。

例: まず main.go を実行してサーバーを起動します。
処理の入口

main関数

プログラムの開始地点です。 Go では func main() から処理が始まります。

例: ルート設定やサーバー起動をここで行います。

Webの基本

受付担当

handler

リクエストを受け取り、レスポンスを返す関数です。 URL ごとの処理を担当します。

例: func handler(w http.ResponseWriter, r *http.Request)
送信情報

request

ブラウザからサーバーに送られる情報です。 URL、メソッド、フォーム内容などが含まれます。

例: フォーム送信時のデータは request に入ります。
返す情報

response

サーバーからブラウザへ返す情報です。 HTML 画面やメッセージなどが含まれます。

例: テンプレートで作った HTML を返します。
入口の名前

route

URL と処理の対応関係です。 どの URL に、どの handler を割り当てるかを決めます。

例: http.HandleFunc("/", handler)
通信方法

HTTPメソッド

リクエストの種類を表します。 GET、POST、PUT、DELETE などがあります。

例: POST は送信、GET は取得に使います。
分岐条件

r.Method

送られてきた HTTP メソッドを確認するための値です。 GET か POST かを見分けるときに使います。

例: if r.Method == http.MethodPost

テンプレート

画面のひな形

template

HTML のひな形です。 Go 側のデータを差し込んで画面を作ります。

例: 同じ HTML を使って、表示内容だけ変えられます。
読み込み

ParseFiles

HTML ファイルをテンプレートとして読み込むための処理です。

例: template.ParseFiles("templates/index.html")
実行

Execute

テンプレートにデータを入れて、HTML として出力する処理です。

例: tmpl.Execute(w, data)
書き込み先

w

レスポンスを書き込むための値です。 テンプレートの出力先として使います。

例: HTML をブラウザに返すときに使います。
入力データ

data

テンプレートに渡す情報です。 タイトルや一覧データなどを入れます。

例: Title や Tasks をまとめて渡します。

DB / SQL

保存場所

Database

データを保存しておく場所です。 この研修では MySQL を使います。

例: タスク一覧を DB に保存します。
DB操作言語

SQL

データベースを操作するための言語です。 取得、追加、更新、削除に使います。

例: SELECT、INSERT、UPDATE、DELETE
接続準備

sql.Open

データベース接続のための準備をする処理です。

例: db, err := sql.Open(...)
接続確認

db.Ping()

DB に本当に接続できるか確認する処理です。

例: 接続情報が正しいかをチェックします。
追加

INSERT

データを新しく追加する SQL です。 Create で使います。

例: INSERT INTO tasks (content) VALUES (?)
取得

SELECT

データを取り出す SQL です。 Read で使います。

例: SELECT id, content FROM tasks
更新

UPDATE

既存のデータを変更する SQL です。

例: UPDATE tasks SET content = ? WHERE id = ?
削除

DELETE

データを削除する SQL です。 Delete で使います。

例: DELETE FROM tasks WHERE id = ?
複数行取得

db.Query

複数行の結果を取得する処理です。 Read でよく使います。

例: 一覧表示するときに使います。
実行

db.Exec

SQL を実行する処理です。 INSERT、UPDATE、DELETE などに使います。

例: データを追加したり削除したりします。

フォーム送信

送信準備

ParseForm

フォーム送信された値を Go が読めるようにする処理です。

例: r.ParseForm()
値の取得

FormValue

フォームから送られた値を取り出す処理です。

例: content := r.FormValue("content")
入力名

name

HTMLフォームの入力欄につける名前です。 Go 側の FormValue と対応させます。

例: <input name="content">
送信先

action

フォームの送信先 URL を指定する属性です。

例: <form action="/tasks" method="POST">
送信方法

method

フォームがどの HTTP メソッドで送信されるかを決めます。

例: GET か POST を指定します。
二重送信防止

redirect

処理後に別のページへ移動することです。 保存後に一覧へ戻すときによく使います。

例: http.Redirect(w, r, "/", http.StatusSeeOther)

Upload

ファイル送信

Upload

ブラウザから送られたファイルをサーバーに保存する処理です。

例: 画像や添付ファイルを受け取ります。
送信形式

multipart/form-data

ファイルを送るときに使うフォームの形式です。

例: enctype="multipart/form-data"
ファイル取得

FormFile

フォームから送られたファイルを取り出す処理です。

例: file, header, err := r.FormFile("file")
保存先作成

os.Create

保存先のファイルを作る処理です。

例: dst, err := os.Create("./uploads/" + header.Filename)
コピー

io.Copy

ファイルの中身を別の場所へコピーする処理です。

例: 受け取ったファイルを保存先へ書き込みます。

Delete

削除対象

ID

どのデータを削除するかを指定する番号です。

例: 一覧から選んだタスクの ID を使います。
URLの値

Query

URL のクエリパラメータを取り出す処理です。

例: r.URL.Query().Get("id")
文字列→数値

strconv.Atoi

文字列を整数に変換する処理です。

例: URL から受け取った ID を数値にします。
ファイル削除

os.Remove

サーバー上のファイルを削除する処理です。 Upload したファイルを消すときに使います。

例: os.Remove("./uploads/" + filename)

Git / GitHub

履歴管理

Git

コードの変更履歴を管理する仕組みです。

例: 変更した内容を記録して戻せるようにします。
共有先

GitHub

Git の履歴をオンラインで管理できるサービスです。

例: 作ったコードを公開したり、履歴を残したりします。
除外設定

.gitignore

Git で管理しないファイルを指定するためのファイルです。

例: パスワードや不要な生成ファイルを除外します。
保存

commit

変更内容を1つの記録として残すことです。

例: 機能を追加したら commit します。
送信

push

ローカルの変更を GitHub などのリモートへ送ることです。

例: git push で変更を共有します。
