Go Webアプリの環境を準備する

このレッスンでは Go アプリを起動するための準備を行います。

Goアプリは以下の構成で動きます。

  • Go Web Server
  • MySQL Database
  • .env 設定ファイル

.env ファイルを作成する

アプリは .env ファイルからデータベース接続情報を読み込みます。

.env が無いとアプリは起動できません

SQL_USER=root
SQL_PASSWORD=9999
SQL_ADDR=localhost:3306
SQL_DBNAME=mermaid
PORT=8080

Goサーバーを起動する

以下のコマンドでGoアプリを起動します。


go run main.go

ブラウザで以下のURLにアクセスします。


http://localhost:8080

演習

main.go を確認してサーバー起動部分を探してください。


http.ListenAndServe(":8080", nil)
