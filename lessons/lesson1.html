Go研修

このレッスンのゴール

この研修では、GoでWebアプリケーションを作ります。 そのために、このレッスンではまず Goをインストールするところから 始めます。

HTML・CSS・JavaScript を触ったことがある方を前提に、 ここでは「Goは初めて」という状態から、 最初のGoプロジェクトを作って、実行できるところ まで進みます。

このレッスンが終わるころには、次の流れが分かるようになります。

  • Go をインストールする
  • Go のバージョンを確認する
  • 最初のプロジェクトフォルダを作る
  • Go module を初期化する
  • main.go を作って実行する
  • この教材全体の流れを理解する

1. Go をインストールする

まずは Go をパソコンに入れます。 Go の公式サイトからインストールできます。

公式サイト: https://go.dev/dl/

インストールが終わったら、ターミナル（Windowsなら PowerShell でも可）で 次のコマンドを実行してみましょう。 


go version

以下のように表示されれば、Go は正しく入っています。 バージョン番号は環境によって異なります。 


go version go1.xx.x darwin/arm64
Go が見つからない場合は、インストール後にターミナルを開き直してみてください。 それでも動かない場合は、PATH の設定を確認します。

2. 最初の Go プロジェクトを作る

Go を入れたら、最初のプロジェクトフォルダを作ります。 ここでは例として go-todo-crud という名前にします。 


mkdir go-todo-crud
cd go-todo-crud

次に、Go module を初期化します。 これが Go のプロジェクトの「土台」になります。 


go mod init example.com/go-todo-crud

このコマンドを実行すると、go.mod というファイルが作られます。 Go はこのファイルを見て、「このプロジェクトはどの module なのか」を判断します。

Go では、まず go mod init をしてから開発を始めるのが基本です。

3. main.go を作ってみる

次に、main.go というファイルを作成します。 Go のプログラムは、まず main パッケージから始まります。 


package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
}

このファイルを保存したら、以下のコマンドで実行できます。 


go run .

実行できると、ターミナルに次のような文字が表示されます。 


Hello, Go!

ここまでできれば、Go の開発を始める準備は完了です。

4. この教材で作るアプリの全体像

この研修では「CRUDアプリ」を作成します。 CRUDとは以下の4つの操作のことです。

  • Create（作成）
  • Read（取得）
  • Update（更新）
  • Delete（削除）

最終的には、データベースに保存された情報を ブラウザから操作できるアプリを作ります。

この研修では、1つ1つの処理を小さく分けて学びながら、 最終的に CRUD アプリとしてつなげていきます。

5. アプリの構成を理解する

このアプリは、主に以下の3つで構成されています。

  • Go Web Server：ブラウザからのリクエストを受け取り、処理する
  • MySQL Database：データを保存する
  • .env ファイル：接続情報や設定をまとめる
Webアプリは「画面」「サーバー」「データベース」の3層構造で動きます。 最初は難しく見えても、役割ごとに分けて考えると理解しやすくなります。

6. .env ファイルとは？

.env ファイルは、設定情報をまとめて管理するためのファイルです。

たとえばデータベースの接続情報をコードに直接書くと、 セキュリティの面でも管理の面でもあまりよくありません。

パスワードをコードに直接書くのは避けましょう。

そのため、環境変数として外に分けて管理します。 以下は一例です。 


SQL_USER=root
SQL_PASSWORD=9999
SQL_ADDR=localhost:3306
SQL_DBNAME=mermaid
PORT=8080

このようにしておくと、コード本体を変えずに設定だけを差し替えやすくなります。

7. Goサーバーとは？

Goサーバーは、ブラウザから送られてきたリクエストを受け取り、 必要な処理をして、結果を返す役割を持ちます。

たとえば以下のコードは、「8080番ポートで待ち受ける」処理です。 


http.ListenAndServe(":8080", nil)
  • http：Web通信を扱う仕組み
  • 8080：ポート番号（アクセス入口）

このあと学ぶハンドラやテンプレートは、 このサーバーの上で動く部品だと考えると理解しやすくなります。
