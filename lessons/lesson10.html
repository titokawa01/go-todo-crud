Readとは？

Readは、データベースに保存された情報を取り出して表示する処理です。

CRUDの中でも、まず一番見える形で動かしやすいのがReadです。

保存したデータを一覧で確認できると、アプリらしさが一気に出ます。

SELECTで取得する

DBからデータを取り出すときは SELECT を使います。 


rows, err := db.Query("SELECT id, content FROM tasks")

このSQLは、tasksテーブルの id と content を取得します。

  • db.Query → 複数行のデータを取得する
  • rows → 取得結果を順番に読むためのもの

取得したデータを読む

取得した rows は、そのままでは画面に出せません。

1行ずつ読み取って、表示用のデータに整えます。 


for rows.Next() {
	var id int
	var content string
	rows.Scan(&id, &content)
}

この流れで、データベースの中身をGoの変数に取り出せます。

画面に渡す

取り出したデータは、テンプレートに渡して一覧画面として表示します。 


data := struct {
	Tasks []Task
}{
	Tasks: tasks,
}

テンプレート側では、配列として受け取り、繰り返し表示できます。

一覧表示のイメージ


tasksテーブル
↓
SELECTで取得
↓
Goで整形
↓
template.Executeで表示
↓
ブラウザで一覧を見る

Readが完成すると、Createで保存したデータを確認できるようになります。

よくある確認ポイント

  • SQLのカラム名は正しいか
  • rows.Next() を使っているか
  • rows.Scan() の順番は合っているか
  • テンプレートへデータを渡せているか
