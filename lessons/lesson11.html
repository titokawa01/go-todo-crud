画面から送信されたデータを受け取る

Webアプリでは、フォームから送られた値を Go サーバー側で受け取ることができます。

この Lesson では、ブラウザから送信されたデータを読み取る基本を学びます。

ここで受け取った値は、次の Lesson 以降で DB 保存やファイル保存につなげていきます。

フォーム送信の流れ


ブラウザのフォーム
↓
HTTP POSTで送信
↓
Goのhandlerで受け取る
↓
送信された値を取り出す
↓
画面表示やDB保存につなげる

データを受け取る処理が分かると、Create の実装に進みやすくなります。

まずはメソッドを確認する

Lesson10 で学んだように、送られてきたリクエストは r.Method で確認できます。 


func handler(w http.ResponseWriter, r *http.Request) {
	if r.Method == http.MethodPost {
		// フォーム送信の処理
	}
}

フォーム送信のときは、まず POST かどうかを確認します。

同じ handler でも、GET と POST で処理を分けると分かりやすくなります。

値を受け取る

Go では、リクエストからフォームの値を取り出せます。 


func handler(w http.ResponseWriter, r *http.Request) {
	r.ParseForm()
	content := r.FormValue("content")
	fmt.Fprintln(w, content)
}

この例では、content という名前の入力欄から値を受け取っています。

r.ParseForm() を呼んでから FormValue を使うと、 フォームの値を取り出しやすくなります。

HTMLフォームの例

ブラウザ側では、次のようなフォームを使います。
  • method="post" → データを送る
  • name="content" → Go側で受け取る名前
  • action="/tasks" → 送信先URL
HTMLの name 属性と、Goの FormValue の名前を一致させます。

よく使う考え方

フォーム送信では、HTML と Go の名前をそろえることが大切です。

入力欄の name が content なら、Go 側でも FormValue("content") と書きます。

この対応がずれると、値を受け取れなくなるので注意しましょう。

処理の流れ


フォームの入力
↓
POSTで送信
↓
handlerで受け取る
↓
ParseForm
↓
FormValueで値を取り出す
↓
次の処理へつなげる

この流れを理解しておくと、Create や Upload の実装がかなり読みやすくなります。

main.go で確認するポイント

main.go では、次の点を探してみましょう。

  • r.Method == http.MethodPost で POST を確認しているか
  • r.ParseForm() を呼んでいるか
  • r.FormValue("content") で値を取り出しているか
  • HTML の name と Go の FormValue が一致しているか
まずは「送る側」と「受け取る側」の名前を合わせることが大切です。
