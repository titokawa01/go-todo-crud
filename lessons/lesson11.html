研修のゴール

この研修のゴールは、GoでCRUDアプリを完成させ、GitHubへ公開できるようになることです。

ここまで学んだ内容をつなげると、ひとつのWebアプリとして動かせるようになります。

ここまで学んだこと

  • GoでWebサーバーを起動する
  • HTTPハンドラでURLごとの処理を分ける
  • テンプレートで画面を表示する
  • MySQLへ接続する
  • Createでデータを保存する
  • Readでデータを一覧表示する
  • GitHubでコードを管理する
  • .gitignoreで不要ファイルを除外する

CRUDアプリの完成イメージ


ブラウザのフォーム
↓
Go Handler
↓
Create / Read / Update / Delete
↓
MySQL Database
↓
HTML Template
↓
ブラウザに表示

この流れを自分で説明できるようになることが、とても大切です。

実務での流れ

実際の開発では、次の順番で進めることが多いです。 


機能を追加する
↓
動作確認する
↓
git status で確認する
↓
git add / commit
↓
git push
↓
GitHubで履歴を残す
作ることと、記録することをセットで進めるのが大切です。
