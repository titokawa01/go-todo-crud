このレッスンのゴール

この研修のゴールは、GoでCRUDアプリを作る流れを理解し、 自分で少しずつ改良できるようになることです。

ここまでで、Goの環境構築から始まり、HTTPハンドラ、テンプレート、DB接続、 Create / Read / Upload / Delete、REST API、フォーム送信の受け取りまで学んできました。

このレッスンでは、個別の知識をもう一度つなげて、 「ひとつのWebアプリとしてどう動くか」を整理します。

ここまで学んだこと

  • Go をインストールして最初のプロジェクトを作る
  • HTTPハンドラでURLごとの処理を分ける
  • HTMLテンプレートで画面を表示する
  • MySQLへ接続する
  • REST API と HTTPメソッドの関係を知る
  • フォームから送信されたデータを受け取る
  • Create でデータを保存する
  • Read でデータを一覧表示する
  • Upload でファイルを保存する
  • Delete でデータを削除する
  • GitHub でコードを管理する
  • .gitignore で不要ファイルを除外する

CRUDアプリの完成イメージ


ブラウザのフォーム
↓
Go Handler
↓
HTTPメソッドで処理を分ける
↓
Create / Read / Upload / Delete
↓
MySQL Database / ファイル保存
↓
HTML Template
↓
ブラウザに表示

この流れを自分の言葉で説明できるようになると、 Webアプリの全体像がかなり見えてきます。

処理のつながりを振り返る

それぞれのレッスンは、単体で完結しているように見えて、実はつながっています。

  • ハンドラ がリクエストを受け取る
  • HTTPメソッド で処理を分ける
  • フォーム送信 から値を取り出す
  • DB に保存したり、取り出したりする
  • テンプレート で画面に表示する
  • Upload / Delete でデータの扱いを広げる
大事なのは、ひとつひとつの関数を暗記することではなく、 「入力 → 処理 → 保存 → 表示」の流れを理解することです。
