HTTPハンドラとは？

Webアプリでは、ブラウザがURLにアクセスすると、Goサーバーがそのリクエストを受け取ります。

そのリクエストに対して、どの処理を実行するかを決めるのが HTTPハンドラ です。

つまり、ハンドラは「URLごとの受付担当」のような役割を持ちます。

URLと処理を結びつける

Goでは、URLと処理を http.HandleFunc で結びつけます。 


http.HandleFunc("/", handler)

このコードは次の意味になります。

  • / にアクセスされたら
  • handler 関数を実行する
http.HandleFunc は「どのURLに、どの処理を呼ぶか」を登録する仕組みです。

Handler関数の書き方

handler関数は、HTTPリクエストを受け取ってレスポンスを返します。 


func handler(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintln(w, "Hello World")
}

このコードは、ブラウザに Hello World を表示します。

引数の意味は次の通りです。

  • w はレスポンスを書き込むためのもの
  • r はブラウザから送られてきたリクエスト情報

処理の流れ

Webアプリは以下の流れで動作します。 


Browser
  ↓
HTTP Request
  ↓
Go Server
  ↓
Handler
  ↓
HTTP Response

ブラウザからのアクセスを受け、Goサーバーが適切なハンドラを呼び出し、結果を返します。

main.go で確認するポイント

main.go では、次の2つを探してみましょう。

  • http.HandleFunc でURLと関数を結んでいる部分
  • handler 関数の中で何を返しているか
この2つが見つかると、GoのWebアプリがどう動いているか理解しやすくなります。
