HTMLテンプレートとは？

GoのWebアプリでは、HTMLテンプレートを使って画面を表示します。

テンプレートを使うと、画面のひな形をひとつ用意しておき、 そこへサーバー側のデータを差し込むことができます。

同じHTMLを使いながら、表示する内容だけを変えられるのがテンプレートの強みです。

テンプレートを使う理由

もしテンプレートを使わずに画面を作ると、HTMLをGoコードの中に直接書くことになり、管理が難しくなります。

テンプレートを使うと、画面の見た目と処理を分けやすくなります。

  • HTMLの修正がしやすい
  • データ表示を整理しやすい
  • ページの共通化がしやすい

初心者のうちは、まず「HTMLを別ファイルに分けて管理する」と考えると分かりやすいです。

テンプレートを読み込む

Goでは template.ParseFiles を使ってHTMLファイルを読み込みます。 


tmpl, err := template.ParseFiles("templates/index.html")

このコードは、templates/index.html をテンプレートとして読み込む処理です。

読み込みに失敗することもあるので、エラーが出たら内容を確認できるようにしておきます。 


if err != nil {
	log.Println(err)
	return
}

この段階では、エラーが起きたことを記録して処理を止める、という考え方を身につけます。

この研修では、まず log.Println(err) で内容を確認できるようにし、 そのあとで必要に応じて処理の止め方を整理していきます。

データをテンプレートに渡す

テンプレートの強みは、Go側のデータをそのまま画面に反映できることです。 


type PageData struct {
	Title string
	Name  string
}

このような構造体を作って、テンプレートに渡します。 


data := PageData{
	Title: "Go研修",
	Name:  "Lesson3",
}

テンプレート内では、{{.Title}} や {{.Name}} のように書いて表示します。

この書き方を使うと、画面ごとに中身だけを変えながら、同じひな形を再利用できます。

テンプレートを実行する

読み込んだテンプレートは Execute で画面に反映します。 


tmpl.Execute(w, data)

この処理で、テンプレートの中にデータが埋め込まれ、ブラウザにHTMLが送られます。

Execute は「テンプレートを動かす」処理です。

処理の流れ


Browser
 ↓
HTTP Request
 ↓
Go Server
 ↓
テンプレートを読み込む
 ↓
データをテンプレートに渡す
 ↓
HTMLを生成して返す
 ↓
Browserに表示

テンプレートを使うことで、画面表示を柔軟に変えられるようになります。

main.go で確認するポイント

main.go では、次の3つを探してみましょう。

  • template.ParseFiles でHTMLを読み込んでいる部分
  • log.Println(err) でエラーを記録している部分
  • tmpl.Execute(w, data) で画面に出力している部分
この3つがそろうと、Goでテンプレートを扱う流れが見えやすくなります。
