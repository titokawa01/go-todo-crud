データベースとは？

Webアプリでは、データを保存するためにデータベースを使用します。

例えばToDoアプリでは、以下のようなデータを保存します。

  • タスク内容
  • 作成日時
  • 完了状態
アプリは「データを保存できる」ことで初めて実用的になります

MySQLに接続する

Goでは database/sql パッケージを使ってDBに接続します。 


db, err := sql.Open("mysql",
"root:9999@tcp(localhost:3306)/mermaid")

この文字列は「接続情報」を表しています。

接続文字列の意味


ユーザー名:パスワード@tcp(ホスト:ポート)/データベース名
  • root → ユーザー名
  • 9999 → パスワード
  • localhost → DBサーバーの場所
  • 3306 → ポート番号
  • mermaid → データベース名
接続情報は.envファイルで管理するのが一般的です

DB接続確認（Ping）

接続できたかどうかは Ping() で確認します。 


err = db.Ping()
if err != nil {
    log.Fatal(err)
}

エラーが出る場合は、接続情報やMySQLの起動状態を確認します。

処理の流れ


Goアプリ起動
 ↓
DB接続（sql.Open）
 ↓
接続確認（Ping）
 ↓
クエリ実行（次のLesson）

DB接続はアプリの「土台」となる処理です。

演習


db, err := sql.Open("mysql", "????")

接続文字列はどの情報で構成されていますか？

  • ユーザー名
  • パスワード
  • ホスト
  • ポート
  • データベース名
