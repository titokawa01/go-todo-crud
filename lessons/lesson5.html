CRUDとは

CRUD は、データベースの基本操作を表す言葉です。

  • Create（作成）
  • Read（取得）
  • Update（更新）
  • Delete（削除）
この4つを理解すると、Webアプリのデータ操作がひと通り見えるようになります。

まずは全体の役割を分けて考える

CRUD は、ただの暗記ではなく「データをどう扱うか」の分類です。

それぞれの役割は次のように考えられます。

  • Create：新しいデータを増やす
  • Read：保存済みのデータを見る
  • Update：保存済みのデータを直す
  • Delete：保存済みのデータを消す

このレッスンでは、まず Create と Read の考え方をしっかり押さえます。 Update と Delete は、このあと追加していく章で扱います。

Create（作成）

Create は、データベースに新しいデータを追加する処理です。 


db.Exec("INSERT INTO tasks (content) VALUES (?)", name)

このSQLは、tasks テーブルに新しい行を追加します。

  • INSERT INTO → データを追加する
  • tasks → 保存先のテーブル名
  • content → 保存する項目
  • ? → 値を安全に差し込むためのプレースホルダ
直接文字列をつなげるのではなく、プレースホルダを使うのが基本です。

Read（取得）

Read は、データベースから保存済みのデータを取り出す処理です。 


rows, err := db.Query("SELECT id, content FROM tasks")

このSQLは、tasks テーブルから id と content を取得します。

  • SELECT → データを取得する
  • rows → 複数行の結果を受け取る

Create は「増やす」、Read は「見る」と考えると分かりやすいです。

Update と Delete はどうつながるか

このレッスンではまだ実装しませんが、Update と Delete も同じ考え方で動きます。 


Create → INSERT
Read   → SELECT
Update → UPDATE
Delete → DELETE

あとのレッスンで、この4つをひとつずつ画面操作と結びつけていきます。

処理の流れ


ブラウザでフォーム送信
 ↓
Goサーバーで受け取る
 ↓
Create なら INSERT
 ↓
Read    なら SELECT
 ↓
DBの結果を画面に返す

この流れが分かると、CRUD アプリ全体の動きが見えてきます。

main.go で確認するポイント

main.go では、次の2つを探してみましょう。

  • db.Exec でデータを追加している部分
  • db.Query でデータを取得している部分
ここで Create と Read の違いを見分けられるようになると、 次のレッスンで実装を読むときに迷いにくくなります。
