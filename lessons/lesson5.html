CRUDとは

CRUDは、データベースの基本操作を表す言葉です。

  • Create（作成）
  • Read（取得）
  • Update（更新）
  • Delete（削除）
この4つを理解すると、Webアプリの基本的なデータ操作が分かるようになります。

Create（作成）

Createは、データベースに新しいデータを追加する処理です。 


db.Exec("INSERT INTO tasks (content) VALUES (?)", name)

このSQLは、tasksテーブルに新しい行を追加します。

  • INSERT INTO → データを追加する
  • tasks → 保存先のテーブル名
  • content → 保存する項目
  • ? → 値を安全に差し込むためのプレースホルダ
直接文字列をつなげるのではなく、プレースホルダを使うのが基本です。

Read（取得）

Readは、データベースから保存済みのデータを取り出す処理です。 


rows, err := db.Query("SELECT id, content FROM tasks")

このSQLは、tasksテーブルから id と content を取得します。

  • SELECT → データを取得する
  • rows → 複数行の結果を受け取る

CreateとReadの違い

Createは「データを増やす」、Readは「データを見る」処理です。 


Create → INSERT
Read    → SELECT

処理の流れ


ブラウザでフォーム送信
 ↓
Goサーバーで受け取る
 ↓
CREATEならINSERT
 ↓
READならSELECT
 ↓
DBの結果を画面に返す

この流れが分かると、CRUDアプリ全体の動きが見えてきます。

演習

UpdateとDeleteのSQLを書いてみましょう。


UPDATE tasks SET content = ? WHERE id = ?
DELETE FROM tasks WHERE id = ?
