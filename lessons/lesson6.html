REST APIとは

REST APIは、HTTPの仕組みを使ってデータをやり取りする設計の考え方です。

ブラウザやフロントエンドから、サーバーに対して「取得・作成・更新・削除」を行います。

このLessonでは、HTTPメソッドごとに処理を分ける考え方を学びます。

HTTPメソッド

RESTでは、HTTPメソッドを使って操作の種類を表します。

  • GET：取得
  • POST：作成
  • PUT：更新
  • DELETE：削除

GET    → 読む
POST   → 追加する
PUT    → 変更する
DELETE → 消す

Goでの分岐

Goでは、リクエストのメソッドを見て処理を分けます。 


switch r.Method {
case http.MethodGet:
	// 一覧取得
case http.MethodPost:
	// 新規作成
case http.MethodPut:
	// 更新
case http.MethodDelete:
	// 削除
default:
	// 対応していないメソッド
}

この分岐によって、1つのURLでも複数の操作を扱えるようになります。

なぜ分けるのか

同じURLでも、操作の種類によって処理は変わります。

  • GETなら一覧を返す
  • POSTなら新しいデータを保存する
  • PUTなら既存データを更新する
  • DELETEならデータを削除する
URLとHTTPメソッドを組み合わせることで、APIの役割が分かりやすくなります。

処理の流れ


ブラウザ / フロントエンド
 ↓
HTTPリクエスト送信
 ↓
Goサーバー
 ↓
r.Method で分岐
 ↓
GET / POST / PUT / DELETE に応じた処理
 ↓
レスポンスを返す

この流れが分かると、CRUDアプリの画面とサーバー処理をつなげやすくなります。
