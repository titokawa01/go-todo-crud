GitHubとは？

GitHubは、コードを保存・共有・管理するためのサービスです。

開発では、変更したコードをGitで記録し、 GitHubに送ることで履歴を残します。

GitHubに上げる前に、変更内容を確認する習慣がとても大切です。

よく使うコマンド

この研修でまず覚えるのは次の3つです。 


git add .
git commit -m "commit message"
git push
  • git add . : 変更をステージングする
  • git commit : 変更を記録する
  • git push : GitHubへ送る

作業の流れ

実際の流れは次のようになります。 


コードを編集
↓
git status で確認
↓
git add .
↓
git commit -m "message"
↓
git push

この流れを繰り返すことで、作業の履歴がGitHubに残ります。

git status で確認する

いきなり push するのではなく、 まず git status で変更内容を確認します。 


git status

ここで、想定外のファイルが混ざっていないかを見ることができます。
