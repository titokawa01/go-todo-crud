画面から送信されたデータを受け取る

Webアプリでは、フォームから送られた値をGoサーバー側で受け取ることができます。

このLessonでは、ブラウザから送信されたデータを読み取る基本を学びます。

ここで受け取った値は、次のLesson以降でDB保存につなげていきます。

フォーム送信の流れ


ブラウザのフォーム
↓
HTTP POSTで送信
↓
Goのhandlerで受け取る
↓
送信された値を取り出す
↓
画面表示やDB保存につなげる

データを受け取る処理が分かると、Createの実装に進みやすくなります。

値を受け取る

Goでは、リクエストからフォームの値を取り出せます。 


func handler(w http.ResponseWriter, r *http.Request) {
	r.ParseForm()
	content := r.FormValue("content")
	fmt.Fprintln(w, content)
}

この例では、content という名前の入力欄から値を受け取っています。

HTMLフォームの例

ブラウザ側では、次のようなフォームを使います。
  • method="post" → データを送る
  • name="content" → Go側で受け取る名前
  • action="/tasks" → 送信先URL

よく使う考え方

フォーム送信では、HTMLとGoの名前をそろえることが大切です。

HTMLの name 属性と、Goの FormValue の名前を一致させます。

演習

次のコードは何をしているでしょうか？ 


r.ParseForm()
content := r.FormValue("content")
