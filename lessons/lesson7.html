このレッスンのゴール

Lesson6 では、フォームから受け取ったデータを DB に保存する Create を学びました。

Lesson7 では、その保存したデータを取り出して一覧表示する Read を学びます。

ここを理解すると、アプリに保存された情報をブラウザで確認できるようになります。

Readとは？

Read は、データベースに保存された情報を取り出して表示する処理です。

CRUD の中でも、まず一番見える形で動かしやすいのが Read です。

保存したデータを一覧で確認できると、アプリらしさが一気に出ます。

SELECTで取得する

DB からデータを取り出すときは SELECT を使います。 


rows, err := db.Query("SELECT id, content FROM tasks")

この SQL は、tasks テーブルの id と content を取得します。

  • db.Query → 複数行のデータを取得する
  • rows → 取得結果を順番に読むためのもの

取得したデータを読む

取得した rows は、そのままでは画面に出せません。

1行ずつ読み取って、表示用のデータに整えます。 


for rows.Next() {
	var id int
	var content string
	rows.Scan(&id, &content)
}

この流れで、データベースの中身を Go の変数に取り出せます。

初心者のうちは、rows.Next() は「1件ずつ順番に見るためのループ」と覚えると分かりやすいです。

画面に渡す

取り出したデータは、テンプレートに渡して一覧画面として表示します。 


data := struct {
	Tasks []Task
}{
	Tasks: tasks,
}

テンプレート側では、配列として受け取り、繰り返し表示できます。

Read は「DBから取る」だけで終わらず、「画面に渡す」ことで初めてユーザーに見える形になります。

一覧表示のイメージ


tasksテーブル
↓
SELECTで取得
↓
Goで整形
↓
template.Executeで表示
↓
ブラウザで一覧を見る

Read が完成すると、Create で保存したデータを確認できるようになります。

よくある確認ポイント

  • SQL のカラム名は正しいか
  • rows.Next() を使っているか
  • rows.Scan() の順番は合っているか
  • テンプレートへデータを渡せているか

main.go で確認するポイント

main.go では、次の流れを探してみましょう。

  • db.Query でデータを取得している部分
  • rows.Next() で1件ずつ読んでいる部分
  • rows.Scan() で変数に入れている部分
  • template.Execute で画面に渡している部分
Read の処理は、「DBから読む」「Goで整える」「画面へ渡す」の3段階で見ると理解しやすくなります。
