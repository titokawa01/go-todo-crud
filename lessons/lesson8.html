GitHubとは？

GitHubは、コードを保存・共有・管理するためのサービスです。

この研修では、ローカルで作業した内容をGitで記録し、GitHubへ送る流れを使います。

GitHubに上げることで、変更履歴を残しながら開発を進められます。

よく使うコマンド

まずは次の3つを覚えます。 


git add .
git commit -m "commit message"
git push
  • git add . : 変更をまとめる準備をする
  • git commit : 変更を記録する
  • git push : GitHubへ送る

作業の流れ

実際の開発では、次の順番で作業します。 


コードを編集
↓
git status で確認
↓
git add .
↓
git commit -m "message"
↓
git push

pushする前に内容を確認する習慣をつけると、事故を防ぎやすくなります。

.gitignoreとは？

.gitignore は「Gitに含めないファイル」を指定するファイルです。

不要なファイルや機密情報を誤ってGitHubに上げないために使います。

.gitignore を設定しておくと、公開してはいけない情報を守りやすくなります。

よく除外するファイル


.env
node_modules/
.DS_Store
  • .env → パスワードなどの情報
  • node_modules/ → サイズが大きい
  • .DS_Store → Macの不要ファイル

.gitignoreの書き方

プロジェクトのルートに .gitignore を作成します。 


touch .gitignore

中身は次のように書きます。 


.env
node_modules/
.DS_Store

よくある事故

最初によく起きるミスを確認しておきます。

  • .env をGitHubにアップしてしまう
  • node_modules を丸ごとpushする
  • 不要ファイルが増えてリポジトリが重くなる
一度pushしたファイルは、あとから完全に消すのが大変なことがあります。
