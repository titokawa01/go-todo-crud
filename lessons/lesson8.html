ここを理解すると、テキストだけでなく画像や添付ファイルのような情報も扱えるようになります。

Uploadとは？

Upload は、ブラウザから送られたファイルをサーバー側で受け取り、保存する処理です。

たとえば、画像、PDF、添付ファイルなどを受け取るときに使います。

フォームの値を受け取るだけでなく、ファイルそのものを受け取るのが Upload です。

Uploadの処理の流れ


ブラウザのフォーム
↓
Goのhandlerで受け取る
↓
multipart form として解析する
↓
ファイルを取り出す
↓
サーバー内に保存する
↓
一覧画面へ戻る

Upload は、Create と似ていますが、 「文字列を保存する」のではなく「ファイルを保存する」という点が違います。

フォーム側の書き方

ファイルを送るフォームでは、enctype を指定する必要があります。

enctype="multipart/form-data" がないと、ファイルは正しく送れません。

ファイルアップロードのときは、通常のフォーム送信とは少し書き方が変わります。

Go側でファイルを受け取る

Go では、まず multipart form として解析します。 


func handler(w http.ResponseWriter, r *http.Request) {
	if r.Method == http.MethodPost {
		err := r.ParseMultipartForm(10 << 20)
		if err != nil {
			log.Println(err)
			return
		}

		file, header, err := r.FormFile("file")
		if err != nil {
			log.Println(err)
			return
		}
		defer file.Close()

		_ = header
	}
}

r.FormFile("file") で、フォームから送られたファイルを取り出せます。

header にはファイル名などの情報が入っています。

ファイルを保存する

受け取ったファイルは、サーバー内の保存先に書き込みます。 


dst, err := os.Create("./uploads/" + header.Filename)
if err != nil {
	log.Println(err)
	return
}
defer dst.Close()

_, err = io.Copy(dst, file)
if err != nil {
	log.Println(err)
	return
}

この処理で、ブラウザから送られたファイルが uploads フォルダに保存されます。

  • os.Create → 保存先のファイルを作る
  • io.Copy → ファイルの中身をコピーする
  • header.Filename → 元のファイル名を使う
保存先のフォルダは事前に作っておきます。 ファイル名の重複には注意しましょう。

保存後の流れ

ファイルの保存が終わったら、一覧画面へ戻すと使いやすくなります。 


http.Redirect(w, r, "/", http.StatusSeeOther)

これで、Upload 後にトップページへ戻れます。

よくある確認ポイント

  • enctype="multipart/form-data" が指定されているか
  • r.ParseMultipartForm を呼んでいるか
  • r.FormFile("file") の名前がフォームと一致しているか
  • 保存先のフォルダが存在しているか
  • 保存後に適切な画面へ戻しているか

main.go で確認するポイント

main.go では、次の流れを探してみましょう。

  • Upload 用のハンドラがあるか
  • r.ParseMultipartForm を使っているか
  • r.FormFile でファイルを取り出しているか
  • os.Create と io.Copy で保存しているか
Upload は、「フォームの受信」と「ファイル保存」の2つがそろって初めて完成します。
