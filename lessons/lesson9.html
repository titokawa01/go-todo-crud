Deleteとは？

Delete は、データベースに保存されたデータを削除する処理です。

不要になったレコードを消したり、間違って登録したデータを取り除いたりするときに使います。

Delete は慎重に扱う必要があります。 どのデータを消すのかを、ID で明確に指定するのが基本です。

Deleteの処理の流れ


一覧画面の削除ボタン
↓
GoのhandlerでIDを受け取る
↓
SQLで対象データを削除する
↓
一覧画面へ戻る

Delete は、対象を特定できるようにしてから実行します。

削除対象のIDを受け取る

削除するときは、どのデータを消すのかを ID で指定します。 


idStr := r.URL.Query().Get("id")

URL のクエリパラメータから、削除したいデータの ID を取り出します。

そのあとで、文字列を数値に変換します。 


id, err := strconv.Atoi(idStr)
if err != nil {
	log.Println(err)
	return
}
URL に入っている値は文字列なので、数値として使うときは変換が必要です。

SQLで削除する

DB からデータを消すときは DELETE を使います。 


_, err := db.Exec(
	"DELETE FROM tasks WHERE id = ?",
	id,
)
if err != nil {
	log.Println(err)
	return
}

このコードは、tasks テーブルの中から指定した ID のデータを削除します。

  • DELETE FROM → データを削除する
  • WHERE id = ? → 対象を1件に絞る
  • db.Exec → SQLを実行する
WHERE がないと、意図しない大量削除になる危険があります。 必ず対象を絞って使いましょう。

削除後の流れ

削除が終わったら、一覧画面へ戻します。 


http.Redirect(w, r, "/", http.StatusSeeOther)

これにより、削除結果が反映された一覧をすぐに確認できます。

もし Upload のファイルも削除したい場合

Upload でサーバーに保存したファイルがある場合は、 DB のレコードだけでなく、ファイル本体も削除したいことがあります。 


err := os.Remove("./uploads/" + filename)
if err != nil {
	log.Println(err)
	return
}

この処理を入れると、DB のデータとサーバー上のファイルをそろえて消せます。

DB の削除とファイルの削除は別処理です。 必要に応じて両方を実行します。

よくある確認ポイント

  • ID を正しく受け取れているか
  • strconv.Atoi で数値に変換できているか
  • DELETE FROM ... WHERE id = ? になっているか
  • 削除後に一覧へ戻しているか
  • Upload したファイルを消すなら os.Remove も必要か

main.go で確認するポイント

main.go では、次の流れを探してみましょう。

  • 削除ボタンから ID を渡しているか
  • r.URL.Query().Get("id") で受け取っているか
  • strconv.Atoi で変換しているか
  • db.Exec("DELETE ...") で削除しているか
  • http.Redirect で戻しているか
Delete は、ID の受け取りと SQL の条件指定がポイントです。
