Createとは？

Createは、フォームから送られたデータをデータベースに保存する処理です。

このLessonでは、画面から受け取った値をDBへ登録する流れを学びます。

ここで「受け取る」と「保存する」がつながります。

処理の流れ


ブラウザのフォーム
↓
Goのhandlerで受け取る
↓
入力値を取り出す
↓
INSERTでDBに保存する
↓
一覧画面へ戻る

Createは、CRUDアプリの最初の完成ポイントです。

フォームの値を受け取る

Lesson7で学んだように、フォームから送られた値は FormValue で取り出せます。 


func handler(w http.ResponseWriter, r *http.Request) {
	if r.Method == http.MethodPost {
		r.ParseForm()
		content := r.FormValue("content")
		_ = content
	}
}

ここで取り出した値を、そのままDB保存に使います。

INSERTで保存する

データを保存するときは、SQLの INSERT を使います。 


_, err := db.Exec(
	"INSERT INTO tasks (content) VALUES (?)",
	content,
)

このコードは、tasksテーブルに新しいデータを追加します。

  • db.Exec → SQLを実行する
  • INSERT INTO → データを追加する
  • ? → 安全に値を渡すためのプレースホルダ
文字列を直接つなぐのではなく、プレースホルダを使うのが基本です。

保存後の流れ

保存できたら、一覧画面へ戻すと使いやすくなります。 


http.Redirect(w, r, "/", http.StatusSeeOther)

これは、保存後にトップページへ移動する処理です。

よくある確認ポイント

  • フォームの name と FormValue が一致しているか
  • SQL文のテーブル名とカラム名が正しいか
  • DB接続が成功しているか
  • 保存後の遷移先が正しいか
